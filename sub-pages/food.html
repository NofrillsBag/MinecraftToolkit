Custom Food

Getting A Custom Texture:

----------

So far, we've been using vanilla only textures. For

custom food

, that doesn't feel too sensible to use an existing texture.

That means, we need to make a

resource pack

which is actually pretty easy, max 6 lines of code.


-> Follow the Video for the folder structure. In later versions, pack.mcmeta may be different.






First, let's add my custom image to

textures/item

.

Then I made a file lavender_mash.json inside

items

so the name of the item. What I pasted in, is the same for any item, all you do is change the name each time.

Another lavender_mash.json inside

models/item

this tells the game how it looks in your hand. I pasted something in again, each time you have a new item simply change the name.

(For tools/weapons you replace generated with handheld.)





We can access the texture in game now with commands.

But we want a custom recipe for

food with custom effects

. So let's go back to Misode.

V


↪

For Item Model

I put the name of the item, minecraft:lavender_mash.

↪

Then, I added food

simply just the amount of natural regeneration, and hunger bars it gives.

↪

Consumable

let's us add effects, to which I chose regen with an amplifier of one, and 40 ticks which is 2s.

Then I added basic extras; name, and lore.






Then, I pasted it into a new file in the recipes in our

DATAPACK

not the resourcepack.

And we're done, all we have to do is add this resource pack folder into our games resource pack folder to see it.
