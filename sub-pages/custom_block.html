Custom Block Shape/Textures
- Overwrite


Blocks


Caveat:

For Custom Blocks, you can only overwrite existing blocks; their

shape, texture and name

.



Block Bench:

So we're going to overwrite the

blast furnace

texture, shape and name.

Do custom Java Block/Item.

Name it the block we're replacing

"blast_furnace" (or do it later like me).


Add a cube;

make it 16x15x16, then a 12x1x12 cube.



Go to paint and

click on the shape you're trying to paint

, then hit create texture(s), name them stove0, stove1.

Now, I'll just paint on this, go to display; change the

scale, rotation and translation

.


Then Save.




Code:

Add "block/" to

models and textures

.

Paste in the model, and change it like I did, and paste in the textures.

Optionally, rename the block. With lang/en_us.json.





And that's it.

Assuming you had no custom shape, you can just save the texture into the folder. If it's the same texture on all faces you just need one 16x16 image, if not then use blockbench to colour a random 16x16 block, then save that as the overwrite.
