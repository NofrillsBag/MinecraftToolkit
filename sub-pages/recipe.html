Recipe for a custom item:



There's a quirk with custom items.


Say I want like a cool custom item for a story map, I can't make the result "paper" then change the name. You might accidentally use it in a crafting a book.

So you use a placeholder item.




Which is why we use the

DEBUG STICK

, it can't be used at all in survival. COMPONENTS (just like the loot table) let you change everything about it,

name, texture, lore.




Looking at the video, we can see I made a recipe for a

DEBUG STICK

that looks like a

Emerald Block

. with a custom name and lore.

For fun, try messing with set attribute modifiers; we'll cover that in custom armour / tool.





For these two custom recipes, we make a new folder called recipe inside our

CUSTOM DATATPACK NAMED

folder.

Then, we can add our two recipes in there. And it's done.





Overwriting Existing Recipes:

Say, you want an existing recipe to be different, remove it, OR you want the result to be modified a bit

(like more amount, name)

.

The code is no different, just where we put it.


> Here I made a recipe for a

Golden Apple

that takes

nuggets

instead of ingots, and gives 2.

The difference is this time, we put it in minecraft/recipes instead of our custom datapack folder.

(This will overwrite the existing recipe)




And that's it! We can make custom recipes, and overwrite existing ones.
