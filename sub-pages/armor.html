Custom Armour
- With Effects


Hypixel Skyblock Esque Armour:


Without Effects:

This only requires THREE new components to make a full "custom set", with a block as a helmet.

A Sea Lantern Helmet, and a blue dyed leather armour set.

This is for a

Lapis Set

.




The new three components that will be used are:

↪

Equippable

for making it equippable evidently, put true for hurt and interact.
↪

Dyed Colour

For dying our armour.
↪

Item Model

for customizing the appearance into blocks.


↪

Extra ones

Max Damage for more durability, Item Name and Lore.




Boots, Leggings and Chestplate, all only need ONE component, the

Dyed Colour

component.

So, I add just the dyed_colour component. Optionally I added max_damage for durability, try doing the similar leggings and chestplate yourself.


Now for the

helmet

, we need to use the item_model component, and the equippable component; and we put the option "head".

↪

Then

add the extra components, max damage 600, name is Lapis Boots, and Custom Lore.



Then, let's get all of our saved generated code, and go to chocolate/recipe and make lapis armour json files for each piece.





Adding Effects:

Ok, cool we have armour that looks different. How about we make it

ACT different?

Like custom effects, like Hypixel Skyblock does it.

All we have to do, is go back to our code. Paste it back into the generator, and for each one add:

Attribute Modifiers



V

Firstly

, we can add the armour, then the armour toughness, then a unique effect, say movement speed.

Each of them need a unique ID

, this is just for organization. Say your datapack_name:item_effect.

For me

: chocolate:lapis_helmet_armor, chocolate:lapis_helmet_armor_toughness, chocolate:lapis_helmet_movement_speed, then chose the slot "legs" etc.

I add 2

for armor and toughness

, only 0.1 for movement speed since that scales a lot.


Now, do the same with the other pieces paste it back in, add the attribute modifiers.





Put the code back in, and now we have a full set of armour,
that looks different, and has custom effects.
