Folder Structure:

So for this module, I am not going to use the generator, because biomes ask for a LOT.

I am going to paste in my code; then tell you what parts you should look at to make customizations, because biomes are very lucrative.

Add three folders in worldgen;

biome, configured_feature, placed_feature

. Then, in minecraft folder, add

dimension

.



Features:

IGNORE THE ERRORS & WARNINGS, THEY ARE FALSE.

Features are the decor of your biome;

trees, rocks, flowers

etc. There is a LOT more you can do, but it'd be

too much to explain



I will explain how YOU can customize these, not so much the structure.



↪

Rock Configured

Configured is the look, this is blob of block, if you want to customize this rock, change the name of the block.

↪

Flower Configured

Amplitude is max at 1, scale and seed are random, if you want to customize simply change the block in the states.

↪

Tree Configured

First section says under the tree is dirt, 2nd is saying how big the leaves are, 3rd is saying the leaves, 4th - 6th explain trunk size and log type, decorators is just leaf litter spawning in each direction.





↪

Rock Placed

Places is the mathematical placement of the rock, i'd recommend only changing count from here.

↪

Flower Placed

Slightly more complex, I'd personally only change the count and rarity, as it's pretty complex math.

↪

Tree Placed

Basically the same as the rock, just says can't be on the water, you can change the count.





Optionally, I have extra code for placing grass. Leave this code as is.

↪

Grass, Grass Patch

Adds grass and tall grass.






Biome:

Now, we can go to worldgen/biome and create the

biome specifications

. Here we can change leaf, grass, short grass, tall grass, sky color, and state which FEATURES (thing we did above) we want.

I then specified

carvers

, which let's caves spawn. Then

spawners let's mob spawn

.
